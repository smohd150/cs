What is secondary storage?

Lesson 1: the four drive types

A storage device is hardware that holds temporary or permanent information. Computers have two kinds:

Primary

Short-term

Holds information only while the computer is running. Volatile: loses data when switched off.

Secondary

Long-term

Nonvolatile: keeps information permanently, even powered off, until erased or overwritten. Can be external or internal.

HDD

The largest drive fitted inside a computer. Nonvolatile, with rotating magnetic disk plates. Stores the OS, software, and files like videos, audio, images, documents.

SSD

Stores data in flash memory chips that need no power to retain data. No moving parts, so it's faster, more durable, and uses less energy than an HDD.

USB flash drive

Removable, rewritable, flash memory. Also called a jump drive. Draws power from the port it's plugged into. Compact, portable, mainly for transferring data.

Tape cartridge

Stores data on small magnetic tapes. Must scan through a lot of tape to retrieve small amounts. Mainly used for archiving and backup.

Lesson 2: Use cases for each drive

How each drive actually works, and when to use it

HDD — how it's built

  1. Disks - a platter of stacked disks
  2. Tracks - concentric circular paths on each disk where data sits
  3. Sectors - each track is divided into smaller segments
  4. Storage map - a part of the drive tracks which sectors are used or free
  5. Actuator assembly - the structure holding the read-write heads

Storing: the computer checks the map for free sectors, then moves the read-write head to store data there. Reading: the computer locates the data's address, moves the head there, and retrieves it.

A controller (small circuit on the drive or motherboard) manages the interaction between computer and HDD.

Best for: digital archives (resists degradation in dry, cool conditions) and mass storage (higher capacity, more cost-efficient than SSD, though slower).

SSD — how it's built

Divided into grids of memory cells: a grid is a block, a row of the grid is a page. SSDs read/write at the page level, but can only write to an empty page.

Writing: finds a block with enough unused pages and writes there. Reading: finds the block with the requested pages, loads the whole block into memory, then displays it. Erasing: only works at the block level — the whole block is copied to memory, erased, updated, and copied back.

Best for: power computing (audio/video processing, rendering, real-time apps), small-form-factor and mobile devices (tolerates altitude, heat, cold, humidity better than HDD) — but NOT long-term archival, since an unpowered SSD can start losing data within 1-2 years.

USB flash drive

Uses the USB mass storage device class (UMS), which lets the OS treat it like an external drive. When connected, the computer auto-recognizes it, installs the driver, and shows it in your file browser like any other drive.

Use cases: troubleshooting and forensics, updating motherboard firmware, installing/booting an OS, extending system memory, running portable apps, system backup.

Tape cartridge

Unlike HDDs/SSDs (dynamic, random access), tapes use sequential access: data is written in one continuous stream, so you must run from start to end to find anything. Storing and reading both start at the index table and traverse to the right address.

Best for: backup and archiving. In a data center, a collection of tape drives is a tape library. Advantages: low unit cost, extremely high capacity, long archival stability.

Tape cartridge

The process varies by manufacturer and drive bay — always check the manufacturer's instructions.

Inserting
  1. Read the manufacturer's instructions
  2. Touch the static-protective package to unpainted metal, then unpack it onto a static-safe surface
  3. Slide the cartridge into the lower optical drive bay
  4. Gently pull the metal tab and slide it in until it fits
  5. Connect power and signal cables
Removing
  1. Remove any locks, then the server cover
  2. Disconnect all cables from the rear
  3. Gently pull the metal tab and push the cartridge outward
  4. Slowly draw it out of the chassis

Lesson 4: Troubleshooting drives

Before you blame the drive, rule everything else out

Secondary storage is permanent and does not need uninterruptible power to retain data, but takes longer to access. Primary storage is temporary and needs uninterruptible power.

Why we need secondary storage: it holds important information, keeps the system working, and retains data even if power is interrupted.

Basic checks before troubleshooting
  1. Turn off the system and unplug the power cord
  2. Check the cabling and all external devices — a recently added device may be the cause
  3. Remove connections to nonessential external devices
  4. Check if the problem is resolved. If not, check the manufacturer's troubleshooting guide

HDD

When to troubleshoot

  • Overheating
  • Strange noises
  • Blue screen errors
  • Stuck spindle motor
  • Won't boot
  • Bad sectors increasing
  • Files corrupted/renamed/missing
  • System crashes, disk errors

Steps to try

  1. Ensure the HDD is receiving power
  2. Ensure the BIOS recognizes the drive
  3. If it boots, check for viruses
  4. Check the validity of the partitions
  5. Check the drive is formatted with an OS-recognized file system
  6. Check for physical or logical disk errors
  7. Check drive status with the disk management utility

SSD

When to troubleshoot

  • Can't read or write a file
  • Active apps freeze
  • Crashes during boot
  • Errors when moving files
  • Slow on large files
  • File system needs frequent repair
  • Drive becomes read-only

Steps to try

  1. Restart in safe mode to rule out a software cause
  2. Ensure critical software/drivers are up to date
  3. Use disk utility software to check the file system
  4. Reinstall the OS using recovery tools if needed
  5. Check S.M.A.R.T. data built into the SSD for reported issues
  6. Update the SSD firmware if it's third-party

USB flash drive

When to troubleshoot

  • Can't read or write
  • Error requiring reformat
  • Temporarily inaccessible
  • Becomes warm or hot

Steps to try

  1. Test every USB port with different drives to find a bad port
  2. Format the drive and try again
  3. Check for outdated/corrupted drivers and update them
  4. Scan for hardware changes and fix them
  5. Update your OS — an outdated OS may not recognize the drive

Tape drive

When to troubleshoot

  • Error messages about the drive
  • Won't eject properly
  • Can't read or write files
  • Blank/blurry/unreadable touch screen
  • Power-on indicator not lit
  • Library/drives don't respond to commands
  • Host software detects a drive problem

Steps to try

  1. Reset by pressing the unload button; power the system off then on
  2. Check the system event viewer for hardware errors
  3. Confirm the OS detects the device and update the OS if not; confirm connectivity with backup software
  4. Install the latest device support update
  5. Update the firmware
  6. Clean the drive with the correct cleaning cartridge
  7. Uninstall any third-party app controlling the device
  8. Check for tape/hardware compatibility issues
