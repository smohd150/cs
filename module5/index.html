What is computer storage?

Lesson 1: why it is needed

Storage is required to process data and store information. A computer could run without storage, but it could only view information. Even browsing the internet needs storage. There are two types: primary and secondary.

Primary

Short-term working area

  • Most common storage in a computer; used for temporary data needs
  • The CPU accesses it directly and in any order, which reduces processing time
  • The working area used to run applications
  • Volatile: needs power; data is only kept while power is on
  • Made from semiconductors, so it costs more than secondary
  • Examples: RAM (most common; the terms are often used interchangeably) and cache memory (also called CPU memory: dedicated memory and the first place the processor looks for instructions. A cache hit skips the slower read from RAM.)
Secondary

Long-term storage

  • Long-term, permanent storage
  • Managed by users: saving or deleting data changes it
  • Inside or outside the computer
  • Not accessed directly by the CPU, so it is slower. Requests go through RAM, then back to the CPU
  • Not volatile: keeps data without power
  • Made from magnetic or optical material, so it costs less
  • Stores large volumes of files; an average PC has about 1-10 TB
  • Most common: the internal hard drive. External examples: CDs, external hard drives, flash drives, magnetic tapes
Think of your brain

Primary: at 12:00 PM you cannot recall every bite of breakfast, or every car you passed, or your exact route to work. Your brain had that information when it needed it, then freed the space for other short-term needs.

Secondary: remembering last summer's family vacation while planning this year's. It takes a moment, but the memories are long-term and permanent: slower to reach, but they are there.

How memory works

Lesson 2: storing and processing data

Computers store data two ways: temporarily and permanently.

  • Temporary storage = memory (RAM): the area used to run programs. Built from millions of transistors and capacitors that form pairs called cells and hold volatile data. Data can be written to any cell in any order, hence random access memory.
  • Permanent storage: where files are kept, commonly the hard drive.
The chef analogy
  • Chef = processor
  • Pantry = permanent storage (the chef can reach all the ingredients/files)
  • Counter = memory. The chef takes ingredients from the pantry and puts them on the counter to cook. With only 2 feet of counter, even an efficient chef can prepare only one meal at a time.
  • When the meal is done (files finalized), ingredients go back to the pantry.
Memory requires power. If you type a document and the computer suddenly turns off before you save, the work is lost: it was only in memory. Saving with a title and location moves it to permanent storage.

Memory and performance

Four things matter: speed, size, type, cost

  • Speed (MHz, megahertz): the number of cycles the RAM performs each second. Higher numbers = more data per second, which often makes the computer faster.
  • Size: big enough for your processing needs, but larger size decreases speed and raises cost. Memory is measured in bytes; most home computers have gigabytes. If you struggle to run large or multiple programs at once, more memory may help.
  • Type: pick the type compatible with your computer: DRAM or SRAM.
  • Cost: memory needs to be fast and hold a lot. Generally, more RAM = a bigger digital countertop and faster programs.

Data, bits and bytes

Lesson 3 begins here

Computers turn text, numbers, pictures, audio and nearly any content into data using the binary numeral system: strings of bits (binary digits), each 1 or 0. The most common storage unit is the byte = 8 bits.

Electronic data sits in digital storage where the CPU can access it directly or indirectly and manipulate it with computations.

The memory hierarchy

Almost all computers order storage by response time (how fast data can be reached)

Closer to the CPU: faster, more expensive, smaller (cache and SRAM, Level 1).
Farther from the CPU: slower, cheaper, larger (DRAM and hard disks, Levels 2 and 3).

Offline storage: cannot be accessed without human interaction; a person must insert or connect it. Used to transfer information. Slow, small size, large capacity. Examples: DVD, CD, USB flash, SD card, portable SSD.

Cache (SRAM) and RAM

Try the cache demo

Cache/SRAM is a storage element the CPU uses for high-speed data access. It holds copies of frequently requested data and instructions from earlier computations, ready for the CPU.

When the CPU needs to read or write a location in RAM, it first checks the cache:

  • Cache hit: the data is in the cache, so it is read from there.
  • Cache miss: not found. The cache creates a new entry, copies the data from RAM, then the request is fulfilled from the cache.
Pick a scenario.
RAM
  • A semiconductor memory module located close to the CPU so it can directly read, write and store data.
  • The main memory / primary storage of modern computers; stores any data currently active and being operated on by the CPU.
  • Random access: the CPU retrieves data immediately on demand, wherever it is. (Sequential access needs a specified order.)
  • Volatile: data is lost when power is interrupted.
  • Two main types of random access semiconductor memory: cache/SRAM and DRAM.

Troubleshooting faulty RAM

Lesson 4

RAM temporarily stores information that devices need to work efficiently, on a memory module: a circuit board fitted into the motherboard slots. Without RAM the device would be extremely slow or might not run at all.

Symptoms of faulty RAM
  • Programs slow down after running for a few hours
  • The system restarts randomly
  • Recently used files become corrupted
  • A blue screen appears at startup
No required order. Evaluate exactly what the computer is doing first, then choose a step. Steps are software-focused or hardware-focused.

Software-focused steps

1

Back up all files

Protect your data first.

2

Use a virus scanner

Rule out malware causing the symptoms.

3

Uninstall new software

Recently added software may be the cause.

4

Make sure the BIOS is up to date

Basic Input/Output System.

5

Ensure correct configuration of RAM

Check the settings match the installed memory.

6

Check POST messages

Power-on self-test messages give clues.

Hardware-focused steps

1

Find the manual and disconnect power

Use the manual to get the model numbers of the memory modules and motherboard. Disconnect power and open the case to examine the hardware.

2

Ensure RAM compatibility

Compare the installed RAM (or replacement RAM) to the requirements in the manual.

3

Confirm correct RAM installation

Some motherboards need slots or DIMMs filled in a particular order. Put modules back gently and listen for the 'click' that shows proper seating.

4

Clean the motherboard and memory modules

Inspect the modules and slots; clean the slots and module connectors with a soft cloth.

5

Perform isolation testing

Remove additional RAM, if any, to rule out faulty hardware. Remove any new hardware you installed and check if the system works.

6

Check system configuration

If you upgraded the memory, revert to the original configuration. If it still fails, the motherboard might need replacing.

7

Ask for a computer technician

If the problem continues, install a memory diagnostic program. Give the technician the steps you followed and your observations.
