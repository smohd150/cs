The language of computers

Lesson 1: define a computer

A computer manipulates data using sequences of numbers made only of ones and zeroes, called binary bits. Each bit is:

  • An on or off electrical signal
  • The smallest piece of information a computer can store
  • Combined with other bits in different ways so you see a photo, a game, or the letters you type on screen

Click the squares to turn bits on and off — this is literally all a computer is doing, just billions of times a second.

Hardware, software & the CPU

The physical parts vs. the instructions

Hardware

The physical stuff

The circuits, chips, wires, plugs, monitor, keyboard, mouse and other mechanical parts that make up a computer.

Software

The instructions

A sequence of instructions, called a software program, that tells the hardware how to work.

The CPU

The central processing unit is the main processor of instructions — it processes and arranges all the ones and zeroes for every command given.

How it all happens

The computer takes an action — a mouse click, a keystroke — and recognizes it as a command. It stores the command, processes it, then displays the output on a monitor, screen or speakers.

The Operating System (OS)

The primary program

The OS is the computer's primary program. A common example is Microsoft Windows. The OS can:

  • Manage software, which in turn controls the hardware
  • Act as the go-between for hardware and every other running program
  • Let you interact with the computer without speaking in ones and zeros
  • Manage the computer's memory
  • Control access to input and output devices
  • Manage running multiple programs at the same time

The four main types of computers

They vary in size, speed and purpose

Size ranges from filling a whole building to fitting in a wristwatch. Speed ranges from 1.5 GHz to over a hundred billion operations per second. Purpose ranges from typing documents at home to running weather forecasts and nuclear research.

Microcomputer

A small computer for a single user — though not limited to one. Ranges from a PC, smartphone or game console up to a workstation or server. Uses microprocessor technology: an entire CPU fits on one chip.

Minicomputer

Usually called a server, optimized to provide services to other computers over a network. Powerful processors, lots of memory, large hard drives. Stand-alone machines used for general business — billing, record keeping. Example: a CAT scanner or tape-backup system in a data center.

Mainframe computer

Built for reliable transaction processing. Supports hundreds or thousands of users at once. About the size of a household refrigerator. Stores far more data, accesses it faster, and has built-in security — used by banks. A mainframe executes many programs concurrently.

Supercomputer

Uses thousands of processors at once (parallel processing). Speed is measured in petaflops — one petaflop = a thousand trillion calculations per second. A supercomputer focuses on a few programs, as fast as possible (the opposite of a mainframe). Used for nuclear research, space exploration, weather forecasting, earthquake research.

China's Tianhe-1 ran massive solar simulations and complex molecular studies. As of November 2018, the US supercomputer Summit was the fastest at 143.5 petaflops. Well-known makers: Cray Research, IBM, Fujitsu.

Types of microcomputers

Microcomputers = 'PCs' — a single CPU on one chip

Personal Computer (PC)

Small, inexpensive, for individual use. Homes: productivity, games, browsing. Business: desktop publishing, spreadsheets, accounting, databases.

Workstation

A powerful single-user computer with a stronger microprocessor and higher-quality monitor than a PC. Used for engineering, desktop publishing, software development, and high-quality graphics work.

Laptop / Notebook

Portable, fits on your lap. Has a CPU, memory and disk drives like a PC, plus a battery. Laptops: 10-18" screens, 3-10 lb. Notebooks: 15" or less, under 5 lb. Today the two terms mostly overlap.

Tablet

A portable computer with a touch-screen interface and no built-in physical keyboard.

Smartphone

Commonly runs iOS or Android. Has more limited functionality than a full computer.

Smartwatch

A wearable microcomputer, e.g. the Apple Watch runs watchOS and has sensors for environment and health monitoring.

Microcontroller

A programmable microcomputer for one niche task — also called an embedded system. Examples: the computer in a car that plays music from your phone, or in a washing machine that senses load size and adjusts the wash.

What is software, really?

Lesson 3: define a program

Every computer is given a set of instructions to do a specific task. That sequence of instructions is a software program. Software interacts with the physical hardware to perform tasks.

Hardware: external & internal

The physical devices that make up a computer

External hardware (peripherals) connect to a PC or laptop and split into:

  • Input devices — take input from the user (keyboard, mouse, webcam, scanner)
  • Output devices — give output to the user (monitor, printer, speakers)
Internal hardware
MotherboardThe backbone of the computer — everything else connects to it.
CPUThe brain: processes the computer's instructions.
RAM (system memory)A short-term storehouse that loads instructions for the CPU.
Graphics cardHandles calculations for graphically intense applications.
Power supply unitProvides power to the motherboard, CPU, and other hardware.

Inside the system unit, the motherboard hosts the CPU, memory, and the fans that cool everything — plus additional key hardware.

How software and hardware interact

Four steps, every time

1

Load

The software program is loaded from its stored location onto RAM.

2

Input

The program receives input: keystrokes, mouse movement, button clicks, or other programs.

3

Process

The data is processed through the CPU.

4

Output

An output is produced, often shown on the monitor.

The four types of software

OS, utility, application, programming

Operating System (OS)Essential — nothing runs without itGives a command-line or graphical (GUI) way to interact with the computer. Manages memory, processes, software and hardware. Examples: macOS, Windows, Linux.
Utility softwareAnalyzes, configures, maintainsExamples: antivirus, backup software, file compression, network utilities. Device drivers are utility software that help external devices talk to the OS.
Application softwareFor the end userInstalled, upgraded or removed by users. Examples: word processors, spreadsheets, graphics programs, databases, web browsers, games, email, photo editors, media players.
Programming softwareSoftware that builds softwareUsed to develop the OS, utility and application software. Main types: machine language, assembly language, high-level language.
