What is a processor?

Also called the CPU (central processing unit)

The CPU is the brain of the computer. It is an integrated circuit built on a single silicon wafer, and it controls all the functions of the computer. It receives and sends instructions and data to peripheral devices and other components.

Modern processors follow the Von Neumann architecture: the program and the data are stored in the same memory. (Earlier machines stored only instructions, so reprogramming was hard and manual.) They are built around digital logic.

A processor must be installed on a motherboard so it can talk to system memory and peripherals.

The five key players
Control Unit (CU)The boss / traffic directorReads the instructions and sends out digital signals that tell the other parts what to do. Example: when it reads 'add two numbers', it switches on the addition circuit.
Arithmetic Logic Unit (ALU)The calculatorDoes the actual math: addition, subtraction, multiplication, division. Also does logic operations: OR, AND, NOR, NOT.
Input/Output units (I/O)The messengerSends and receives instructions and data to and from system memory (RAM) and peripherals (mouse, keyboard, monitor, printer).
RegistersThe fastest tiny notepadSmall memory inside the CPU that holds the input values and the result. They are the fastest memory there is. Their size sets the CPU's capacity: a 32-bit CPU handles inputs up to 32 bits, a 64-bit CPU up to 64 bits.
CacheThe quick-access shelf (optional)Temporary storage built into the CPU chip. Faster than RAM but slower than registers. In modern chips it can take up to 50% of the chip area.
Speed:Registers (fastest) → Cache → RAM (slower)
Remember: The CU, ALU and I/O units are the essential parts. Registers store input and results. Cache is optional but important.

Processor sockets

A processor's pins must match the motherboard's socket. There are four main types.

DIP

Dual Inline Package

  • Used in the very first microprocessors (Intel 8086 and 8088)
  • Allowed solder-free installation for PC makers
SIP

Single Inline Package

  • Also called a 'slot 1' processor
  • Used in Intel Pentium II and III and matching Celeron versions
PGA

Pin Grid Array

  • The pins are on the processor and go into holes in the socket
  • Name is PGA + the number of pins (e.g. PGA 478)
  • Most processors come in PGA form
LGA

Land Grid Array

  • The socket has the pins; they touch pads on the processor's body
  • Used in Intel Pentium 4 and matching Celeron, early Xeon servers, and modern Intel i7
Be gentle: sockets use ZIF (zero insertion force). It is easy to bend or snap a pin, which can cause permanent or on-and-off problems like broken data, bad timing or overheating.

Accessing a processor

5 steps before you can take the processor out

1

Turn off the computer

Make sure it is off and the power cord is unplugged. On a laptop, also detach the battery. Disconnect all external cables.

2

Release body static

Static electricity can ruin a whole circuit. Wear an ESD (anti-static) wrist band and be properly grounded.

3

Open the computer case

Every case opens differently and may need special tools. Check the manufacturer's documentation.

4

Unplug the power connectors

Unplug the power connector from the power supply to the motherboard, and the processor fan's connector.

5

Remove the heat sink and cooler fan

Carefully unlock them. If stuck on with thermal paste, wipe it ALL off with an alcohol wipe. Old paste causes heat problems later or too much paste when new paste goes on.

Removing a processor

7 steps

1

Remove dust

Before opening the LGA latch, clear dust from the motherboard, heat sink, fan and processor.

2

Remove heat sink & fan, wipe off paste

Use an alcohol wipe to get every bit of old paste off. Let the alcohol fully evaporate before reinstalling.

3

Unlock the processor latch

LGA: open the latch. PGA: open the retaining frame.

4

Hold the processor

Hold it from opposite edges with your fingers (gloves preferred). Never touch the top or the pins.

5

Lift it straight out

Pull the processor straight up out of the socket.

6

Store the old processor

Wipe old paste off its surface. Keep it in a dust-free, static-free package. This protects the pins on a PGA chip.

7

Clean up the dust

Vacuum the motherboard, holding the vacuum several inches away without touching the board, or use a static-free, lint-free cloth.

Installing a new processor

13 steps. Make sure system power and the motherboard are disconnected first.

1

Choose the right processor

It must be compatible with the motherboard: socket, clock, bus speed and other components.

2

Unpack the processor

It comes in a sealed package that protects it from static, dust and knocks. Unpack carefully.

3

Clean the motherboard

Make sure there is no dust and that you are grounded. Wear gloves if you can.

4

Open the retaining frame

Open the PGA socket or the LGA retaining frame.

5

Place the processor, no force

Align it correctly; look for notches or a pin-1 marking. The socket is ZIF (zero insertion force), so it drops in without pushing. Forcing it bends or breaks pins.

6

Replace the retaining frame

Once the processor is seated, close the retaining frame.

7

Check the fan is compatible

Make sure the cooling fan matches the heat sink.

8

Apply the heat sink compound

Check the heat sink suits the new processor. Put on thermal paste BEFORE the heat sink and fan. Use a small amount: too much leaks over the sides and can short-circuit.

9

Secure the heat sink and fan

Follow the number order on the heat sink for the screws. If there is no order, tighten in a cross-diagonal pattern.

10

Connect the fan's power cable

Plug it into the CPU fan header on the motherboard.

11

Connect the power connector

Connect the power connector from the power supply to the motherboard.

12

Close the computer case

Use the same specialized tools and the manufacturer's document.

13

Connect system power

Reconnect power and all external devices, then power on and check everything works.
